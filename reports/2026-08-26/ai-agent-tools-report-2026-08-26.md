### 1. Munder Difflin

- **功能描述**：本地多 Agent 编排框架（Electron + Pixi.js 像素办公室）。把你已有的终端编码 CLI（Claude Code、Codex、Grok、Kimi Code、Qwen、Gemini CLI、OpenCode、Copilot、Cursor 等）封装为常驻的「克隆」Agent，由 GOD Agent（Michael）统一调度；通过本地 git 仓库实现共享邮箱/黑板/记忆，支持端到端加密的 Agent 间通信、Slack/Webhook 触发器、HITL 审批门与三级熔断器。相似度：高——多 Agent 编排与自动化工作流，与 WorkBench 的 Agent 编排能力高度重合；核心差异是强调本地自托管、BYOK、不上传代码到托管平台。
