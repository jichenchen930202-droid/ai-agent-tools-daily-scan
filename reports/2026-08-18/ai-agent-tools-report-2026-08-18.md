## 详细信息

### 1. Avernet

- **功能描述**：蚂蚁集团 inclusionAI 团队开源的多智能体协作基础设施（community V0.1，2026-08 公开开源引爆关注）。定位为「协作层」：标准化 Agent 的注册/发现/邀请、共识达成、跨团队协作与治理（身份/授权/权限/生命周期管理），支持自由聊天与 Leader-Follower 等协作模式、共享上下文、可追溯执行日志与反馈进化闭环；兼容 OpenClaw 等开放协议及异构 Bot/第三方引擎，提供 Docker 与本地 singlebox 双部署路径，不绑定单一模型（DeepSeek/GLM/通义/Kimi 等均可接入）。
- **免费使用方式**：Apache-2.0 开源，可免费自部署（Docker 镜像 / 本地 ./scripts/singlebox.sh）；单机即可拉起核心 + 前端工作台 + 5 个本地测试 bot，无任何模型绑定或授权费用。

### 2. Rerun

- **功能描述**：无代码 AI Agent 构建与编排平台（Product Hunt 2026-07-21 上线）。通过模板库或自然语言描述快速生成 Agent，连接 180+ 工具（Gmail/Slack/Notion/Stripe 等），事件/定时触发 7×24 运行；提供实时可视化仪表盘（每步运行/交接/日志/Token 用量），敏感操作（付款、外发邮件）前暂停等待人工审批；每个工作区运行在独立私有 Box，支持「我们的模型 / 自有 API Key / 本地模型」。
